# Steam 饰品自动上架

本地运行的 Steam 社区市场饰品批量上架与重定价工具。目标是扫描账号中所有可出售饰品，根据最近 30 天行情计算价格，提交市场挂单，并在超时未售后切换定价策略。所有 Steam Guard 上架确认均由用户在手机端手动完成。

> 当前状态：`v0.2.0` 登录会话阶段。已经包含内置 Steam 官方登录窗口、持久化浏览器会话、启动自动恢复、退出清理、本地控制台和定价骨架；尚未接入真实库存和市场操作。当前版本不会执行上架。

## 核心原则

- 仅在本机运行，默认监听 `127.0.0.1`。
- 不保存 Steam 密码、Steam Guard 密钥或恢复码。
- 首次通过内置 Steam 官方页面登录，后续加密恢复会话。
- 所有真实上架必须由用户在手机端确认。
- 上架前默认使用演练模式（dry-run）。
- 所有金额均使用整数最小货币单位，避免浮点误差。
- 第一批支持人民币（CNY）与印度卢比（INR）钱包。

## 计划功能

1. 扫描全部库存并筛选可出售资产。
2. 拉取并清洗每种饰品最近 30 天价格与成交量。
3. 提供稳健中位价、市场跟随价、趋势价和快速出售价。
4. 批量创建挂单并跟踪手机确认状态。
5. 超时未售自动撤单、切换策略并重新提交。
6. 设置最低到账金额、批次限额、黑名单和高价值保护。
7. 保存完整的操作审计记录。

## 本地启动

需要 Python 3.11 或更高版本。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m playwright install chromium
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

打开 <http://127.0.0.1:8765>。

运行测试：

```powershell
python -m pytest
```

代码检查：

```powershell
python -m ruff check .
```

## 配置

配置使用 `STEAM_LISTER_` 前缀的环境变量：

```powershell
$env:STEAM_LISTER_DRY_RUN = "true"
$env:STEAM_LISTER_HOST = "127.0.0.1"
$env:STEAM_LISTER_PORT = "8765"
```

真实市场接入完成前，不应关闭演练模式。

## 开发路线

### 里程碑 1：登录会话（已完成）

- 内置 Steam 官方登录窗口，不使用自制密码表单。
- 使用 Chromium 持久化配置保存会话，不读取或保存密码。
- 下次启动自动恢复并在线验证登录状态。
- 退出时清除本地 Cookie 和网页存储。

### 里程碑 2：只读 Steam 接入

- 库存分页与可出售资产识别。
- 当前挂单和市场历史同步。

### 里程碑 3：30 天定价

- 价格历史缓存。
- 异常成交清洗。
- 完成四种定价策略。
- 手续费及卖家到账反算。
- CNY/INR 解析与取整测试。

### 里程碑 4：受控上架

- 上架计划预览。
- 单件和批量提交。
- 待手机确认状态跟踪。
- 幂等保护、限速和失败恢复。

### 里程碑 5：自动重定价

- 挂单在售时间统计。
- 策略阶梯与最低价格保护。
- 自动撤单和重新计算。
- 重挂后重新进入手机确认队列。

## 安全说明

Steam 社区市场操作依赖 Steam 网页端能力，其中部分接口并非稳定的官方公开 API，可能随时变化或触发限流。项目不会尝试绕过 Steam 的安全验证、地区限制或请求限制。接入真实交易前必须进行小额、低频测试，并保留紧急停止开关。
